# Трекер времени — версия 4

Расширение Chrome (React 19, Vite 8, Tailwind 4, TanStack Query, Axios, Manifest V3) для учёта рабочего времени с двусторонней синхронизацией через Google Apps Script.

## Что нового

- **Переименование** проектов без потери идентификаторов и истории.
- **Удаление** проекта вместе с его сессиями после подтверждения (запрещено, пока сессия активна или на паузе).
- **Описание задачи** перед каждым новым запуском сессии; при возобновлении после паузы прежнее описание сохраняется.
- **Шесть столбцов** в каждом листе-дате Google Sheets: `Проект`, `Начало`, `Конец`, `Длительность`, `Время для трекера`, `Описание задачи`.
- `Время для трекера` — число в десятичных часах, автоматически вычисляемое по длительности: 30 мин = 0.5, 45 мин = 0.75; точность до 4 знаков.
- Двусторонняя синхронизация изменений из Google Sheets с сохранением ID записи в developer metadata строки.

## Установка / обновление

**До обновления обязательно сделайте резервную копию Google Таблицы и локального хранилища расширения** (в DevTools расширения: `copy(JSON.stringify(await chrome.storage.local.get(null)))`). Не удаляйте установленное расширение и не меняйте его ID: `chrome.storage.local` привязан к ID расширения.

1. В существующем Google Apps Script проекте замените **весь** `Code.gs` содержимым файла `google-apps-script/Code.gs`.
2. В **Project settings → Script properties** убедитесь, что заданы `SYNC_SECRET` и `SPREADSHEET_ID`.
3. Выберите **Deploy → Manage deployments → Edit → New version → Deploy**. Откройте URL `/exec`: `doGet()` должен вернуть `"version":"4.0.0"`.
4. Обновите исходники расширения в вашем проекте, **сохранив свой `.env`**. Если файла ещё нет, скопируйте `.env.example` в `.env` и замените переменные.
5. Выполните `npm ci`, затем `npm run lint && npm run build`.
6. В `chrome://extensions` нажмите Reload для текущего unpacked extension, либо выберите каталог `dist/` при первой установке.
7. Нажмите **Синхронизировать**. Уже созданные листы с четырьмя столбцами автоматически получат новые заголовки E/F, сохранив строки и metadata.

## Проверка

1. Создайте проект и кликните «Старт». Введите «Правки главной страницы», затем «Начать сессию».
2. Через 30–60 секунд нажмите «Стоп». Описание появится в истории; строка появится во вкладке текущей даты в Sheets.
3. Переименуйте проект; название поменяется в сохранённых записях таблицы после синхронизации.
4. Отредактируйте длительность или описание задачи в Sheets, затем синхронизируйте: приложение обновится.
5. Удалите сессию / проект и проверьте удаление строк из Sheets.

Разработческая проверка без npm-зависимостей: `npm run test:smoke (или node --test tests/*.test.mjs без установки зависимостей)`.

## Ограничения

- Десятичные часы рассчитаны из столбца «Длительность», а не являются независимой редактируемой величиной. Изменения в E перезаписываются при синхронизации.
- При удалении проекта **удаляется вся история** проекта, в том числе в Google Sheets.
- Скрипт не переводит старые проектные вкладки (до схемы с листами-днями) в новый формат: они остаются нетронутыми как архив.
- Данные в разных устройствах без индивидуальной авторизации не имеют гарантий транзакционной согласованности.
- `VITE_SYNC_SECRET` встраивается в JavaScript при сборке, поэтому такое подключение допустимо только для частного использования. Нельзя распространять собранное расширение с секретом.
- Chrome background alarms работают периодически; обновления не гарантированы мгновенно.


## Индикатор запросов (v4 UI)

В popup есть единый ненавязчивый спиннер: он отслеживает активные `useQuery`/`useMutation` через `useIsFetching`/`useIsMutating` и прямые запросы `requestSync` в Service Worker через `TrackerPage`. Для коротких операций видимый индикатор появляется только спустя 180 мс, не блокируя интерфейс и не влияя на тиканье таймера. В кнопках добавлены небольшие локальные спиннеры.
